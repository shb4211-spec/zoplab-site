WHAT YOU BUILD · 이 책에서 만드는 것

각 부마다 완성품이 하나씩 남아요

0부

시작하기

자동화를 세 조각으로 나눠 보고, 도구 3개(Make, Google, Gemini) 계정과 비용 계산표를 준비해요.

1부

고객 문의 자동 분류와 답변 초안

설문지 → 시트 → AI 분류 → Gmail 임시보관함. 테스트 문의 10건으로 결과를 확인해요.

2부

매일 아침 도착하는 업무 리포트

예약 실행으로 시트 데이터를 모으고, AI로 요약해 메일로 받아요.

3부

콘텐츠 기획 → 초안 → 검토 대기

아이디어 시트에서 개요와 초안을 만들고 Google 문서로 정리해요. 게시 전엔 사람이 검토해요.

4부

내 업무 규칙을 익힌 AI 비서

업무 규칙 문서를 쓰고 Gemini Gem으로 비서를 만들어 1~3부 자동화에 연결해요. 한계와 주의점도 함께 적었어요.

5부

만든 자동화를 일로 연결하기

범위와 견적 정하는 법, 납품 방식, 계약·유지보수·데이터 책임, 첫 고객 찾기 체크리스트.
